Clean Home

Turn on Watch Next

Watch Next shows the Continue Watching cards of the app you focus. It is off by default. Android does not show a permission box for it on a TV. You grant it once from a computer. It takes about 5 minutes.

What you need

  • Clean Home installed on the TV.
  • A computer with adb (Android platform-tools).
  • The TV and the computer on the same Wi-Fi.

1. Turn on debugging on the TV

  1. Open Settings, then System, then About.
  2. Scroll to Android TV OS build.
  3. Press OK on it 7 times.
  4. Press Back.
  5. Open Developer options in Settings, System.
  6. Turn on Wireless debugging. If your TV has no such item, turn on USB debugging and connect with a USB cable instead.
  7. Leave the screen open. It shows the IP address and port.

2. Pair the computer (first time only)

  1. On the TV, choose Pair device with pairing code.
  2. On the computer, run this with the pairing IP and pairing port from the TV:
    adb pair IP:PAIRING_PORT
  3. Type the 6-digit code.
  4. Run this with the main IP and port:
    adb connect IP:PORT
  5. Run adb devices. The TV should show as device.
  6. If the TV asks to allow debugging, choose Allow.

The port changes after the TV restarts. Read it again on the TV.

3. Grant access

Run this one command:

adb shell pm grant com.cleanhome.tv android.permission.READ_TV_LISTINGS

If more than one device is connected, add -s IP:PORT after adb.

4. Turn it on in the app

  1. Open Clean Home on the TV.
  2. Open Settings, then Watch Next.
  3. Set Show on Home to On.

5. Check that it worked

  1. In Clean Home, focus an app that has Continue Watching items, such as a streaming app you used lately. Cards should appear.
  2. If the Watch Next page says access is missing, repeat step 3.
  3. To check from the computer, run:
    adb shell dumpsys package com.cleanhome.tv | grep READ_TV_LISTINGS
    It should print granted=true.
  4. If access is granted and no cards show, the app you focused may have published none. Watch something in that app first.

6. Turn debugging off

  1. On the TV, open Developer options.
  2. Turn Wireless debugging (or USB debugging) off.

The grant stays after debugging is off.

Undo

  1. To stop showing cards, set Settings, Watch Next, Show on Home to Off. Clean Home then reads nothing and clears its poster cache.
  2. To take the permission back, turn debugging on again (steps 1 and 2) and run:
    adb shell pm revoke com.cleanhome.tv android.permission.READ_TV_LISTINGS
